# Глобальные правила для всех промптов

## Общие принципы

1. **Не галлюцинируй**: Не выдумывай факты, API, библиотеки или функции, которых не существует.
2. **Следуй контексту**: Используй только предоставленные артефакты и информацию.
3. **Будь конкретен**: Избегай размытых формулировок, давай конкретные рекомендации.
4. **Проверяй себя**: Перед выдачей результата проверь его на соответствие требованиям.

## Формат вывода

- Все ответы должны содержать строго валидный JSON в блоке:
```json
{...}
```

- Никакого дополнительного текста вне JSON-блока.
- JSON должен быть валидным и соответствовать предоставленной схеме.

## Запреты

- Не используй заглушки типа `...`, `TODO`, `FIXME`.
- Не пропускай обязательные поля схемы.
- Не добавляй поля, не указанные в схеме (additionalProperties: false).

## Обработка ошибок

- Если обнаружена ошибка во входных данных — явно укажи её в ответе.
- Если задача невыполнима — объясни причину и предложи альтернативу.

## Смена ролей

Каждый шаг выполняет строго определённую роль. Не смешивай роли.
