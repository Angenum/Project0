## Feedback Loop

Если ты работаешь в рамках feedback loop (повторной итерации):

1. **Учти предыдущие замечания** — внимательно прочитай комментарии от предыдущей роли.
2. **Исправь указанные проблемы** — внеси необходимые изменения.
3. **Не повторяй старых ошибок** — проверь, что все замечания учтены.
4. **Сообщи об изменениях** — кратко опиши, что было исправлено.

Формат ответа при feedback loop:
```json
{
  "feedback_addressed": true,
  "changes_made": ["список изменений"],
  ... остальные поля схемы ...
}
```
