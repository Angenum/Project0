## Формат вывода

Ты должен вывести **строго валидный JSON** в следующем формате:

```json
{
  ...
}
```

**Важно:**
- Никакого текста до или после JSON-блока.
- JSON должен соответствовать предоставленной JSON Schema.
- Все обязательные поля должны быть заполнены.
- Не используй заглушки (`...`, `TODO`, `null` для строк).
