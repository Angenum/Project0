## Обработка ошибок

Если ты обнаружил проблему во входных данных или контексте:

1. **Не игнорируй ошибку** — явно опиши её в ответе.
2. **Предложи решение** — укажи, как можно исправить проблему.
3. **Не продолжай с ошибочными данными** — если задача невыполнима, остановись и Сообщи почему.

Формат сообщения об ошибке (если применимо):
```json
{
  "error": {
    "type": "тип_ошибки",
    "message": "описание ошибки",
    "suggestion": "предложение по исправлению"
  }
}
```
